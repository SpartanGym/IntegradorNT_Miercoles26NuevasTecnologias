## 🚀 Descripción

**NeoApp** es el módulo de análisis de datos del ecosistema **Spartan Gym**, enfocado en el procesamiento y análisis de datos utilizando Python.

Este componente permite transformar datos del gimnasio en información estratégica para la toma de decisiones.

---

## 🎯 Objetivos

- 📊 Analizar datos de usuarios, pagos y membresías  
- 📈 Generar métricas clave  
- 🔍 Detectar patrones  
- 📉 Visualizar datos  
- 🤖 Preparar datos para futuros modelos  

---

## 🧩 Tecnologías utilizadas

- 🐍 Python 3.x  
- 🐼 Pandas  
- 🔢 NumPy  
- 📊 Matplotlib  
- 🎨 Seaborn
