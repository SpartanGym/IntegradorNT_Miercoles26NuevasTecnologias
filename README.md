## 🚀 Descripción

Este proyecto corresponde al módulo de **análisis de datos con Python** de la aplicación **Spartan Gym**, un sistema completo para la gestión de gimnasios.

Su objetivo es procesar, analizar y visualizar datos generados por el sistema para obtener información útil que apoye la toma de decisiones.

---

## 🏋️ Spartan Gym (Proyecto principal)

Spartan Gym es una aplicación full stack compuesta por:

- ⚛️ Frontend en React  
- ☕ Backend en Spring Boot  
- 🐍 Análisis de datos con Python  

Este repositorio se enfoca únicamente en el componente de análisis de datos.

---

## 🎯 Objetivos

- 📊 Analizar datos de usuarios, pagos y membresías  
- 📈 Generar métricas clave del gimnasio  
- 🔍 Detectar patrones de comportamiento  
- 📉 Visualizar información relevante  
- 🤖 Preparar datos para futuros análisis avanzados  

---

## 🧩 Tecnologías utilizadas

- 🐍 Python 3.x  
- 🐼 Pandas  
- 🔢 NumPy  
- 📊 Matplotlib  
- 🎨 Seaborn
